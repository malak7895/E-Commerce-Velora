# ✨ Velora — Fashion E-Commerce Website

**Velora** is a modern and responsive fashion e-commerce website designed to provide a smooth and enjoyable online shopping experience.

## 🛍️ Features

* 🏠 Modern Home Page
* 👗 Products Showcase
* 🔎 Product Search
* 🏷️ Category Filtering
* 🛒 Shopping Cart
* ➕➖ Increase & Decrease Product Quantity
* 🗑️ Remove Products from Cart
* 💰 Automatic Cart Total
* 🌙 Dark Mode
* 💾 Local Storage Support
* 📱 Fully Responsive Design
* 💬 Contact Form
* ✨ Product Details Modal

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

## 🎯 Project Goal

The goal of Velora is to create a clean, modern, and user-friendly fashion e-commerce experience using front-end web technologies.

## 🚀 Getting Started

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start exploring Velora!
